수신 대기 중...
교무실 PC에서 방송을 송출하면 이곳에 방송 자막이 표시되고 음향 시스템으로 음성 안내가 시작됩니다.

학교 음향 시스템(앰프) 연동 가이드

  • 방송실 PC의 오디오 출력(AUX/LINE OUT 또는 USB 오디오 인터페이스) 케이블이 학교 메인 방송 앰프 입력단자에 연결되어 있는지 확인하세요.
  • 원격 방송 시 방송실 앰프의 해당 채널 볼륨이 켜져 있어야 교실 스피커로 송출됩니다. (자동 릴레이 제어기가 없는 경우 앰프 전원을 상시 대기 모드로 유지하세요.)
  • 동일한 네트워크나 외부 인터넷 환경 모두에서 학교 채널 코드만 일치하면 실시간으로 작동합니다.

학교 방송 채널 및 배포 설정

교무실 PC와 방송실 PC가 서로 통신하기 위한 고유 식별 코드입니다. 우리 학교만의 영문/숫자 조합 코드를 입력하세요.

영문 대소문자, 숫자, 하이픈(-) 사용 가능 (공백 자동 제거)

PC별 전용 접속 링크 복사 (배포 후 즐겨찾기용)

웹 호스팅 배포 후 아래 링크를 각 PC 브라우저에 즐겨찾기해 두면 해당 화면과 채널로 즉시 열립니다.

API 키가 없어도 PC 내장 기본 음성으로 모든 방송 기능이 무료로 정상 작동합니다.
